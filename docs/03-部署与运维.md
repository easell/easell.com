## 二、域名与 DNS：全 Cloudflare（2026-11-14 老板裁定）

**策略：阿里云不再参与任何环节**——不买 ECS、不用 OSS、不用阿里云 DNS。域名只保留在阿里云作为注册商（改 NS 必须在注册商做），解析与托管全部在 Cloudflare。

当前状态（2026-11-14 实测）：
- NS 仍在阿里云（dns23/dns24.hichina.com）
- `www` A 记录 → 47.96.152.225（旧 ECS 已到期停机，HTTP 502），**站点当前离线**
- Cloudflare 账号内尚无 easell.com 的 zone；Pages 侧 `easell.com` / `www.easell.com` 已挂好，状态 `pending`

落地三步（第 1、2 步只能人工，第 3 步由 AI 接管）：

1. **Cloudflare 面板加站点**：dash.cloudflare.com → Add a site → 输入 `easell.com` → 选 Free → 复制分配的两个 NS（形如 `xxx.ns.cloudflare.com`）
2. **注册商改 NS**：阿里云域名控制台 → easell.com → DNS 修改 → 填这两个 NS（只是换解析服务商，域名所有权不变）
3. **AI 接管**（NS 生效后）：
   - 校验 zone 状态 → active
   - 补 DNS：`www` CNAME → `easell-com.pages.dev`（Proxied）、根域 CNAME 平滑映射（Proxied）
   - 刷新 Pages 自定义域 → active，证书自动签发
   - 开 Always Use HTTPS；`easell.com` 301 → `www.easell.com`（canonical 固定 www）
   - 线上验收：13 页 200、证书链、canonical、sitemap

> 若要全自动（省掉第 1 步）：需要一个 API Token，权限 `Zone:Edit` + `Zone:Create`（Account 级）+ `DNS:Edit`。当前 wrangler OAuth 只有 `zone (read)`，所以 API 建不了 zone（实测 403 `com.cloudflare.api.account.zone.create`）。

备案说明：湘ICP备2022019296号-1 原为阿里云接入。解析转到 Cloudflare 属境外接入，按工信部规则原接入会失效。当前按老板指令照常上站展示；若日后要在大陆合规运营，需重新办理接入（届时再议托管，本次不涉及阿里云）。

## 三、GitHub App 授权（一次性，影响自动构建）

Cloudflare Pages 的 GitHub App 是"选定仓库"授权。新仓库要进安装范围：
https://github.com/settings/installations → **Cloudflare Pages** → Configure → Repository access 勾选 `easell.com` → Save。

未授权时推送不会自动触发构建（部署记录里没有 `github:push`）；可用 Deploy Hook 手动触发兜底。
