落地三步（第 1、2 步只能人工，第 3 步由 AI 接管）：

1. **Cloudflare 面板加站点**：dash.cloudflare.com → Add a site → 输入 `easell.com` → 选 Free → 复制分配的两个 NS（形如 `xxx.ns.cloudflare.com`）
2. **注册商改 NS**：阿里云域名控制台 → easell.com → DNS 修改 → 填这两个 NS（只是换解析服务商，域名所有权不变）
3. **AI 接管**（NS 生效后）：
   - 校验 zone 状态 → active
   - 补 DNS：`www` CNAME → `easell-com.pages.dev`（Proxied）、根域 CNAME 平滑映射（Proxied）
   - 刷新 Pages 自定义域 → active，证书自动签发

   - 线上验收：13 页 200、证书链、canonical、sitemap

> 若要全自动（省掉第 1 步）：需要一个 API Token，权限 `Zone:Edit` + `Zone:Create`（Account 级）+ `DNS:Edit`。当前 wrangler OAuth 只有 `zone (read)`，所以 API 建不了 zone（实测 403 `com.cloudflare.api.account.zone.create`）。

**踩坑记录（重要，下次建站直接照做）**：Pages 自定义域的证书走 **HTTP-01 校验**（访问 /.well-known）。若在建域**之前**就开启 Always Use HTTPS 或根域 301，校验请求被拦截，域会永久卡在 pending。正确顺序：

1. zone active + DNS 就绪 → **先**加 Pages 自定义域，等两域名 active、证书签出（约 2–5 分钟）
2. **再**开 Always Use HTTPS 和 301 规则

若已经卡 pending：关掉这两项 → DELETE 再 POST 一次 Pages 域名（重新触发校验）→ active 后恢复。

API Token（`easell-dns`）权限：Zone:Edit / DNS:Edit / Zone Settings:Edit / Single Redirect:Edit，All zones。token 存于 `scripts/.cf_api_token`（已 gitignore，勿提交）。wrangler OAuth 无 zone 写权限，zone/DNS/设置操作一律用这个 token。



Cloudflare Pages 的 GitHub App 是"选定仓库"授权。新仓库要进安装范围：
https://github.com/settings/installations → **Cloudflare Pages** → Configure → Repository access 勾选 `easell.com` → Save。

未授权时推送不会自动触发构建（部署记录里没有 `github:push`）；可用 Deploy Hook 手动触发兜底。

## 备案现状与裁定（2026-11-14，方案 A）

**裁定：维持 Cloudflare 托管，不做 ICP 备案。** 理由与约束记录如下。

1. **为什么不能备案**：ICP 备案按「服务器物理位置」判定，与建站工具无关。Cloudflare Pages 的源站在境外节点，不属于境内接入，
   且 Cloudflare 不是中国大陆持牌接入服务商（无资格做备案接入商）。**要备案只能把站放到境内服务器**（阿里云/腾讯云轻量，备案服务码＋主体材料＋人脸核验）。
2. **旧备案号的处置**：`湘ICP备2022019296号-1` 为易采通 2022 年阿里云接入备案，ECS 2025-08-13 到期后接入失效。
   工信部备案查询接口现需动态鉴权（WAF 返回 403），第三方查询站全为前端渲染，本次未能在线核实其是否已注销。
   **风险判断：号码若已被注销而页脚照挂，属虚假备案号，比不挂更糟**（政企客户一查即露）→ 故本轮从页脚撤下。
3. **代码层实现**：`src/data/site.ts` 的 `icp` 置空；`SiteFooter.astro` 条件渲染——`icp` 有值显示备案号（链工信部），
   为空则显示「统一社会信用代码 91430104MABEXYD64」（链国家企业信用信息公示系统 gsxt.gov.cn，任何人可核验）。
   **恢复方法：核实在 beian.miit.gov.cn 仍有效后，把号码填回 `icp` 字段，构建部署即恢复。**
4. **方案 A 的代价（已知并接受）**：无备案号——部分政府采购/国企招标把「网站已备案」列为资质门槛；百度收录与国内访问速度略逊于境内节点。
5. **若日后改走方案 B（迁回境内备案）**：已有备案号→办「新增接入」；已注销→走「首次备案」（初审 1–3 天＋管局 5–20 天）；
   备案核验期间须关闭 Cloudflare 橙云代理（解析必须指向境内 IP），通过后再决定是否切境内 CDN；上线 30 日内另做**公安联网备案**。
