# 05 · 「行业动态」页更新口径与操作手册

> 页面：`/news/`（导航第 6 项「行业动态」）｜数据层：`src/data/press.ts`｜首页有「最新动态」前 4 条摘要块
> 建立：2026-11-14。老板要求：后期有相关新闻可以同步更新进来。

## 一、更新流程（每次只动 press.ts）

1. **收集**：核对自 `PRESS_UPDATED` 以来，以下来源的新发布：
   - 国家：国家发展改革委、生态环境部、商务部（政策/标准）
   - 湖南省：省发改委 `fgw.hunan.gov.cn`、省生态环境厅、省商务厅、省邮政管理局（年度重点工作方案、监管数据）
   - 长沙市：市发改委 `fgw.changsha.gov.cn`（季度现场核查通报）
   - 联盟/专委会：湖南省可降解塑料产业创新联盟（内部文件，无公开链接也可收录，注明文号）
2. **核实**：每条必须有「发布机构 + 日期 + 可点开的原文链接」；查不到出处的消息一律不上。
3. **录入**：在 `PRESS` 数组按时间位置插入（页面自动倒序渲染），同步更新 `PRESS_UPDATED`。
4. **发布**：`npm run build` → commit → push（IP 直连）→ 触发 deploy hook（见 docs/03）。
5. **汇报**：告知老板新增了哪几条、来源链接。

## 二、收录纪律（沿用全站红线）

- 政府文件**只引用标题、文号、要点**；红头文件原件/扫描件含联系人手机号，**绝不上站**。
- **不写领导个人姓名**（只写单位，如「省发改委资环处」）；**不点名第三方商户**（写业态）。
- 数字必须**注明口径与时点**（如「联盟 2022 年 8 月口径：四批次 47 家企业、102 种制品」），不与本站 quality 页「23 家」等不同源数字混用。
- 环保宣称挂标准；PLA 只称工业可堆肥；不转述「微塑料致癌」类未经证实说法。
- 政策**废止/替代**要及时跟进：如 2020 年商务部第 61 号公告已于 2023-06-20 被《商务领域经营者使用、报告一次性塑料制品管理办法》（商务部、发改委令 2023 年第 1 号）替代——policy 页与动态页都按新办法表述。

## 三、字段说明（press.ts）

| 字段 | 说明 |
|---|---|
| `date` | `'YYYY-MM-DD'` 精确到日；只知月份写 `'YYYY-MM'`（页面显示 `MM.DD` / `MM`） |
| `tag` | 政策 / 核查 / 标准 / 数据 / 行业（五类，各配一种淡色标签） |
| `url` | 原文链接，政府官网优先；无链接可省略 |
| `docNo` | 文号，如 `湘发改环资规〔2020〕857 号` |
| `inner` | 对应站内页（`/policy/` `/inspection/` `/model/` 等），引导读者继续看 |

首页「最新动态」块自动取 `PRESS_SORTED` 前 4 条（有 `url` 跳原文，否则跳 `inner`）。

## 四、自动化

- 「易采通行业动态月度巡检」：每月 1 日 09:00 自动检索上述来源，有新内容按本手册流程上站并部署，无新内容仅汇报。
